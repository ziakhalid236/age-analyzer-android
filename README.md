# 🎂 Age Analyzer Android App

An elegant, modern, and highly precise Android application designed to calculate your exact age from the moment of your birth until this very second!

## ✨ Features
- **Precise Calculation:** Tells you your age in Years, Months, Days, Hours, Minutes, and Seconds.
- **Modern UI:** Built with **Material Design 3** for a smooth and beautiful user experience.
- **Interactive Date Picker:** Easily select your birthday with a sleek calendar interface.
- **Real-time Insights:** Get a detailed breakdown of your life journey.

## 🚀 Tech Stack
- **Language:** Kotlin
- **UI Framework:** XML with Material Components
- **Architecture:** Modern Android Development (MAD) principles
- **Design:** Material Design 3 (M3)
